# Retail Sales Analysis & Interactive Dashboard

## Project Overview
An Excel-based data analytics project exploring 100 sample retail orders to identify sales trends and business performance.

## Tools Used
- Microsoft Excel
- Excel formulas: SUMIFS, COUNTIFS, AVERAGE
- PivotTables and PivotCharts
- Interactive slicers
- KPI dashboard

## Key Performance Indicators
- Total Net Sales
- Total Orders
- Average Order Value
- Cancelled Orders and Cancellation Rate

## Key Business Insights
- Top category: Electronics
- Best-performing month: February
- Best-performing city: Bengaluru
- Cancellation rate: 17%

## Project Files
- `Retail_Sales_Analysis_Project.xlsx` — Excel workbook and dashboard

To practice data cleaning, sales analysis, KPI reporting, and interactive dashboard creation using Microsoft Excel.
